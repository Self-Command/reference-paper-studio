字体核验：[37945165806](https://github.com/Self-Command/reference-paper-studio/actions/runs/37945165806)的`font-face-probe.json`记录所选SC字面cmap与PDF实际“骨、直、令”字符CID一致。PDF的JP名称来自可共享的内部字体表，不能单独据此认定选错中文字形。旧视觉记录已明确补充这一证据修正，原收据保持原样。

候选技术迭代：`region.body@2`和`table.three-line@2`接入原生LaTeX栏与CALS；实际生成内容经受限语法回读，未知额外文字拒绝。Word数据行禁止拆页，页码使用母版原生PAGE域；Word续表名称仍有缺口。递归宽度预算和子树重复估算已按根因修复，等待新模型校样确认。新增同输入、同母版的重复导出程序，比较可编辑数学及逐页图像；对应结果不能预先标为通过。

本次保留的诊断：37944090286中CALS在multicols自动续栏缺表头；37947571523中检测器窄空格及区域定位错误导致2失败、126通过，页图已保留并据此修正检测。37946303569因深嵌套触发旧宽度估算指数复杂度而取消；37947137583、37947561154为已替代的运行而取消，取消不等于测试通过。

37948906164原模型双输出构建成功、自动验收失败，实际Word保留。独立诊断[37950645493](https://github.com/Self-Command/reference-paper-studio/actions/runs/37950645493)确认LaTeX越栏位于表格行内公式后的逗号、复杂度说明的句号与文献`networks[C]//Proceedings`；没有把这些误报成显示公式的越栏。37950096303因诊断脚本后缀书写错误失败，该错误修正后重跑；诊断不编译或改写被检查版本。随后加入附着标点宽度预留、文献斜线的可选断点及有限段落应急伸展，等待双输出/重复导出的最新结果。

37951239529的132项检查通过，原模型只剩符号表L行后逗号的4.32pt越栏；自动验收仍失败，不发布。诊断[37952047900](https://github.com/Self-Command/reference-paper-studio/actions/runs/37952047900)定位到新增行内数组的左右`arraycolsep`未计入宽度；修复只在实际生成数组时预留10pt，不让透明递归容器反复扣宽度。原模型回读及9类回归继续按最新提交独立核验。

基线缺陷与失败也保留：37926336985因原参数表无名称而拒绝；37927413351因LaTeX中文控制词边界而失败；37931954754中的M6没有丢失符号，但进入了编号保留区域；37933282342虽自动通过，M10视觉换行仍过碎；37937212172因编号新结构尚未纳入模板约束而失败，后续收紧登记几何并重验。37935634819为官方LibreOffice镜像下载超时，不是模型或公式校验通过/失败证据。
