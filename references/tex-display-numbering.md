# LaTeX显示公式编号与实际度量

当前生成链路使用同一可逆OMML换行及Pandoc转换结果，随后由amsmath执行TeX显示排版。Word编号中心改善不能证明TeX编号也正确。

真实回归37962872728的两种变体第2页，M2、M6、M8、M10等公式的编号被移到数学对象下方。字符回读和未越栏检查均不能代替编号锚点检查。已在[逐页报告](../docs/visual/37962872728.md)记为F06，保持未验收。

上游[LaTeX维护者的问题说明](https://github.com/latex3/latex2e/issues/115)解释，居中显示算法会考虑公式、编号和间隔，空间不足时可移动编号。因此物理公式宽度和数学树是否完整是不同问题。这是根因调查线索，不能只凭上游描述确认本稿的具体宽度。

`Skill CI / math-measure`只读取指定运行中已生成的`latex/main.tex`和报告，复用相同字体前导，在Actions用XeLaTeX的原生盒度量得到每式宽、高、深和编号宽，并生成孤立校样。结果记录源码指纹、来源运行及诊断运行，保留原产物不修改。

输出的居中所需空间是诊断估计，不作为放宽门禁的理由；实际孤立字框、原稿页图和编号区域共同判断。不能用任意`raisetag`、字号缩小、公式图片或跨栏来隐藏问题。

母版规则与正式生成路径在度量确认前不因诊断报告改变。未知标签、重复标签、无显示对象、度量缺项或诊断页数变化均明确拒绝。这个入口与其他执行程序一样在非Actions环境阻止运行，测试也只在Actions执行。
