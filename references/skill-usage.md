# 技能用途与独立使用

能力、输入、输出、前置条件及调用示例以 [能力目录](../catalog/skill-catalog.yaml) 为唯一登记来源。总技能与说明技能读取同一文件，不维护不同的技能列表。

| 需求 | 调用入口 | 获得什么 |
|---|---|---|
| 材料零散，希望先规划 | `$reference-paper-studio` | 工作顺序、所需材料与审批事项 |
| 只了解技能如何使用 | `$paper-studio-help` | 每个技能的说明卡、调用方法、模板就绪情况 |
| 学习参考论文或比赛要求 | `$paper-reference-research` | 来源证据、结构与格式规则、冲突和待确认项 |
| 提炼并审查数学模型 | `$paper-model-review` | 正规模型稿与验证证据问题清单 |
| 按确认结构写MD | `$paper-md-write` | 真实内容的MD论文，暂不生成Word |
| 只检查已有MD | `$paper-md-review` | 逻辑、数学、图表和引用审查报告 |
| 新建或扩展模板 | `$paper-template-compose` | 组件组合、固定母版与验收状态 |
| 导出已确认稿件 | `$paper-export` | Word、LaTeX、校样、预览和首版诊断 |
| 查看成品有何问题 | `$paper-visual-review` | 21项逐页复检报告和视觉附件 |
| 修复已批准的问题 | `$paper-revise` | 修订版、差异、云端复检，保留首版 |

用户可直接调用任何一个入口，不必从总技能重新开始。说明与只读审查不启动生成或修订。总技能应复用已有材料、字体选择和仍然有效的授权；缺少当前操作真正需要的信息时才询问。

正式导出至少需要：当前MD与图片/文献资源、MD内容确认、登记模板身份、中文/英文/数学字体选择、对应快照的生成授权。字体可选开源方案，也可提出其他字体；缺少字体文件或对应母版时，先完成字体变体验收，不能静默换字。

`template.json` 中未就绪的能力、候选母版和待审MD，必须明确说明当前限制。绿色工程检查不等于官方投稿合规、数学正确或用户审批。所有执行性检查与转换均提交GitHub Actions；本地仅阅读、编辑、提交、查询、下载与查看云端页图。
