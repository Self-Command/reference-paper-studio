# 项目流程与独立使用

正式内容源是 manuscript.md。开发说明、证据、选择和审批保存旁置记录，不插入正式论文。

总技能优先使用已有材料和授权；只有缺少影响当前操作的信息时才问用户。写MD前读取用户模板；没有时介绍适用的登记模板与章节作用供确认。

新模型论文先凝练、验证、作者确认。方向获批不是数学验证。已发表稿件纯格式整理注明科学结论未重新验证。

字体至少询问中文、英文和数学方案，推荐思源宋体/Noto Serif CJK SC、Liberation Serif、Latin Modern Math；也可选择宋体、Times New Roman、Cambria Math或自定义。缺字体不得静默替换。字体变体先云端登记，填充任务不修改母版。

MD内容确认和生成Word授权分别记录；明确一次批准多个事项时复用，不重复询问。只检查不修复。第一版保留，视觉复检后给Word、页图和问题报告，用户批准范围后再修复并重验收。

所有测试、转换、编译、渲染和验证只在GitHub Actions。当前Codex负责写作与看图，不默认启动子代理或额外模型服务。
