# 长表组件与验收边界

候选 `region.body@2` 使用 LaTeX 原生双栏；`table.three-line@2` 使用免费开源 [CALS 2.4.2](https://ctan.org/pkg/cals) 处理自然换页、换栏及重复表头。前置信息是固定通栏区域，正文中的表格仍在单栏内。旧版引擎保留原实现。

采用依据：[37945165806](https://github.com/Self-Command/reference-paper-studio/actions/runs/37945165806) 的 160 行独立探针验证了数据完整、每个续栏重复表头及表下题。CALS 在 `multicols` 中的自动续栏探针失败，记录在 37944090286，因此没有采用该组合。正式适配器另用 160 行压力样例检查续表名称、三线规则、实际单元格回读及篡改拒绝；不能把可行性探针当作适配器验收结果。

代码只使用 CALS 接口，不复制其源码。共同边框组件当前要求上、下边框等粗；不支持的合并单元格或边框组合明确失败。字体由登记模板决定，不能为容纳长表缩小字体。

Pandoc 没有 CALS 表格阅读器。审计副本通过受限生成语法读取**实际 LaTeX**中的题名、表头及单元格，转换成普通长表供 Pandoc 回读。不从输入 AST 重建审计内容；题名未调用、未知额外文本、单元格数量变化或不完整括号均拒绝。续表装饰不计作科学正文。

Word 数据行禁止拆页、表头使用原生重复机制。Word 的可见续表名称与逐栏重复题名尚未完整实现，必须保留这一缺口；不能用 LaTeX 的通过结果替代 Word 验收。正式套件不因此获得发布或安装资格。
