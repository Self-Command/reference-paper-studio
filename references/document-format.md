# 双格式文档

统一 Markdown + LaTeX 公式、元数据、图件和文献库。公式稳定 ID 与显示编号分离：模型稿 preserve，论文 sequential。
默认通栏前置信息与双栏正文，英文摘要可在 front 或 end。三线表只处理数据表；公式编号不是数据表。图题在图下、表题在表上；中英文题注共用一个对象 ID。
Word 公式使用 OMML；导出失败时不能图片化。对长公式使用等价换行、跨栏块或扩展公式区域，不能缩小到不可读。未经允许不更改数学关系或变量字体语义。
开源字体默认为 Noto Serif CJK SC 与 Liberation Serif，替代宋体/Times New Roman 的事实必须写入报告。Word 与 LaTeX 允许不同分页，内容与引用必须一致。

交叉引用标记使用 `{{eq:M1}}`、`{{fig:F1}}`、`{{tab:T1}}`。公式 ID 来自 `\tag{M1}`，图表可指定 Pandoc 对象 ID，未指定时按出现顺序分配 F1/T1。两种输出共用 `reference-map.json`。现有稿件手写的 M1–M30 在保留编号模式下保持原样；改为连续编号前，将涉及编号的手写引用改为标记，避免留下旧编号。

使用相邻 `表1… / Table 1…` 段落作为表题时，共同 AST 会识别并归入数据表，修正表下题。题注译文必须由作者提供或核实，排版器不会虚构译文。图使用 Markdown 图片说明作为图下题。表格与复杂公式按需跨栏，正文恢复双栏。

精确字体入口是 profile 的 `fonts.cjk/latin`；第一版云端只预装开源字体。精确字体应由合法字体文件与锁定版本的自有 runner 镜像提供，并在 Actions 安装，不能依赖本机字体。不存在的字体直接失败。字号、页边距和栏距均为配置值，未测得的参考值须明确标记为工程默认值。

Word 的短公式保留在正文栏内，超出栏宽的公式才跨栏。所有分节（包括文档末尾的节）必须显式使用连续类型；分节标记不得继承正文行高成为空白行。云端报告记录逐页内容垂直范围，低于正文高度 35% 的非末页会阻止验收；末页允许自然留白。视觉审阅仍需检查栏间空洞、公式与编号碰撞及不合理的单独成页，不能仅凭内容与公式保留就判为版面合格。

Word 引擎调整先按 [模板对比](word-engine-comparison.md) 完成同一母版与同一内容的云端对比。候选库的分页估计不能代替实际兼容校样；正文内容通过也不能代替版面通过。
