# 固定模板与内容填充

正式技术链为 Pandoc 共同 AST → 受限内容对象 → python-docx/lxml 填充版本母版 → OOXML 检查 → 云端双输出校样。Node 库对比只保留为实验记录，不参与正式生成。

## 模板契约

套件候选使用 `schema_version: 2` 与 `template: {id, version, variant, font_profile, manifest_sha256}`。原参考候选为 `reference-journal-v1 / 2.0.0`，首页或篇末摘要使用 `front|end`。旧版 `template_id/template_version` 仅按明确兼容契约映射，不能视为新版授权。模型稿保留原公式 ID，论文稿连续编号并保存映射。请求中的 `profile` 和任何物理排版参数均拒绝。

两种母版均是实际 DOCX 资产，由云端一次生成并附 SHA-256 清单。填充只使用登记资产，不从输入稿件复制样式、主题、分节、页眉或页脚；仅导入内容所需图片、链接和经过固定缩进处理的列表语义。

原参考模板固定区域为：通栏前置信息、完整双栏正文、可选的通栏篇末英文摘要。其他模板按登记组件确定单栏或双栏。正文不允许新分节或跨栏。字体先由用户选择并登记字体变体；字号、页边距、段距、列表缩进、题注和表格线由模板决定。Markdown 中图片宽度与其他物理属性被清除并记录，原始排版命令明确失败。加粗、斜体及上下标保留。成品仍可编辑，不使用密码保护。

## 对象规则

公式为原生 OMML。编号区与公式区固定在一栏内，无边框的公式布局表独立标记，不套用数据表三线规则。长公式按数学对象边界确定性换行，保留既有分段与多行结构；记录每次前后树和路径，恢复时先核验变换后树，再逆序恢复，必须与转换前数学树一致。

行内公式也受正文栏宽和表格单元格宽度约束。超宽的分段函数可把每个分支的值、条件按原顺序上下排列，普通矩阵不得改变列数。换行后的行首运算符用无边框数学分组保持可编辑；此兼容表示须经过逐条云端符号渲染检查。集合差使用 U+2216 避免兼容渲染器把 ASCII 反斜线误作转义。上述表示转换全部写入可逆记录，不改变模型定义。

LaTeX 复用经过恢复检查的数学换行决定，输出实际排版正文和内容审计正文；两者均检查。数据表按固定列宽换行，可在行间换栏/分页，行内不拆；图片等比限制在单栏宽度内。当前个人审阅变体按用户要求**图上题、表下题**；官方变体按已确认规则另行登记。候选原生栏/CALS实现与未完成的Word续表题名见[长表组件说明](long-table-backend.md)。遇到不能安全容纳的对象、合并表格或未支持对象，定位并失败，不改栏数、字号或内容。

## 证据与验收

正文双栏和图表规范来自参考共识；英文摘要位置和双语题注的差异使用指定官方模板消歧。A4、2.2 cm 页边距、0.6 cm 栏距和 10 pt 正文为 v1 工程参数，尚非精确测量的期刊要求。开源字体 Noto Serif CJK SC、Liberation Serif、Latin Modern Math 的替代差异必须记录。

检查完整分节序列（front 为 1/2，end 为 1/2/1）、样式/资产指纹及正文无分节。再测量实际 PDF 正文区域的栏边界和栏间空隙；存在属性不等于实际页面合格。逐页查看云端 PNG，并绑定运行及产物指纹记录视觉收据；所有脚本、转换、测试和渲染只能运行在 Actions。

视觉收据同时绑定 Word 文件、两套 PDF 和全部页面预览。收据核验只记录视觉状态，**不会生成发行资格或允许安装**。套件发布还必须满足九类MD审定、承诺模板验收和其他P6条件；旧版收据也不能绕过这一门禁。不得用本地重打包替换已验证的包。

## 原有论文的纯格式整理

已有公开论文只做格式整理时使用 `document_kind: format`，不触发新论文写作，也不宣称重新验证论文结论。保留原始 Markdown、图片和来源记录的指纹；不得为通过验收手动改写源公式。

MD前置信息使用已登记的`title/authors/affiliation/abstract/keywords`加`_zh|_en`角色。其他来源的YAML字段不能被清空后静默丢失；未知作者、基金、DOI等字段明确报错，先确认内容映射或扩展登记组件，再生成新的内容快照并绑定授权。不能把不支持的科学元数据当作可删除的物理格式。

常规 Markdown 之外，导入器接受语义性的 LaTeX 题名、作者、摘要、章节和文字转义。没有定位标记的 `footnotetext` 作为明确的源注释块保留，记录在 `semantic-import-ledger.json`，不能猜测脚注落点。嵌套 aligned 只删除该层对齐标记，分段函数和矩阵内部列分隔符保留。原始 HTML、物理排版指令和未知对象仍报错。

首次使用测试先冻结技能提交与输入文件，按参考分析、内容审查、导出、查看校样的流程运行。首次 DOCX 及全部诊断产物原样保存；自动验收失败也不把修订版称为首次效果。格式审查的失败结论独立于论文的科学结论。
